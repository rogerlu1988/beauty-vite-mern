# Beauty Booking App (Vite + MERN)

This is a full-stack beauty service booking platform, similar to SkipTheDishes but for cosmetic and beauty professionals.

## Tech Stack
- Frontend: React (Vite), TailwindCSS
- Backend: Node.js, Express.js, MongoDB (Mongoose)
- Auth: JWT (3 roles: client, professional, admin)

See the backend and frontend folders for setup instructions.
